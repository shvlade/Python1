# Основы Python

> Базовые упражнения Python: условия, циклы, факториал, списки и случайные числа.

**Стек:** Python · стандартная библиотека

## Темы

Условия, циклы, факториал, операции над списками и фильтрация случайных чисел.

## Запуск

Запускайте выбранный скрипт из папки репозитория, например:

```bash
python "1 задание.py"
```

Некоторые задания запрашивают ввод в консоли. Каждая задача — самостоятельный учебный пример.
